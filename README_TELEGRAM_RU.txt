OBBY SMASH RUSH — Telegram 0.7.9 / Stars + восстановление окна

ЧТО В ЭТОЙ ВЕРСИИ
- Магазин Telegram Stars в гардеробе и улучшениях, без новой кнопки на основном экране.
- Каждый из 39 дополнительных скинов — 25 Stars; весь текущий гардероб (40 костюмов) — 199 Stars.
- «Тренер скорости» — 49 Stars: навсегда +50% скорости за ручной тап, с округлением до целых. Автотренировка не меняется.
- «Монетный чемпион» — 49 Stars: навсегда +50% монет за стены в забегах, с округлением до целых. Рекламные награды и задания не умножаются.
- Все покупки разовые, подписок нет. Один и тот же бонус повторно не складывается.
- Обычные скины по-прежнему доступны за игровые монеты или необязательную рекламу.

ВАЖНО ДЛЯ УСТАНОВКИ
Для Stars нужны и Web-билд 079, и новый Worker 003 с базой D1. Одной замены файлов на GitHub для оплаты недостаточно.
До настройки Worker платёжные кнопки показывают недоступность магазина; игра продолжает запускаться и работать.
Новых токенов платёжного провайдера не нужно. BOT_TOKEN и WEBHOOK_SECRET остаются прежними и хранятся только в Cloudflare.

1. ОБНОВИ WORKER
Открой существующий Worker worker.bbodaska.workers.dev → Edit code.
Скопируй ВЕСЬ текст из ObbySmashRush_Worker_003.txt в редактор вместо прежнего кода и нажми Deploy.
Прежние GAME_URL, BOT_TOKEN, WEBHOOK_SECRET оставь в настройках Worker. Приветствие /start и его переводы сохранены.

2. ДОБАВЬ БАЗУ ПОКУПОК
Cloudflare → Storage & databases → D1 → Create database. Имя, например: obby-purchases.
Открой существующий Worker → Bindings → Add binding → D1 database.
Variable name / Binding name: OSR_STORE.
Выбери созданную базу, сохрани и нажми Deploy, если панель предложит.
Базу не удаляй при будущих обновлениях: в ней журнал оплат, купленные товары и обращения.

3. ПОДКЛЮЧИ ОПЛАТУ
Открой https://worker.bbodaska.workers.dev/.
Введи свой прежний WEBHOOK_SECRET в поле страницы.
В разделе магазина нажми «Подготовить базу».
Затем в разделе 2 нажми «Проверить бота» → «Подключить бота и оплату».
Это обновляет список событий webhook: message + pre_checkout_query, не очищая очередь событий.
Проверь показанные цены и нажми «Включить магазин». Эту кнопку нажимает владелец игры после просмотра цен.
Если появится ошибка, скопируй её текст. Токен бота в чат не присылай.

4. ОБНОВИ WEB-БИЛД
Распакуй ObbySmashRush_Telegram_Web_079.zip и скопируй всё содержимое в локальную папку существующего GitHub-репозитория Obby-Smash-Rush с заменой файлов.
index.html, index.js, index.wasm и index.079.pck должны лежать в корне.
В GitHub Desktop: Commit to main → Push origin. Дождись успешного GitHub Pages.
Полностью закрой и снова открой Mini App. Внизу настроек должна быть «Версия 0.7.9».
Адрес игры остаётся https://baskbuster.github.io/Obby-Smash-Rush/.
Обновление использует отдельный index.079.pck для защиты от старой копии пакета в кэше. Старые index.pck и index.078.pck больше не используются.

КАК ПОКУПАТЬ
После первого забега открой Гардероб → нужный скин → Stars. Либо Улучшения / Гардероб → Магазин Stars.
Цена и предмет ещё раз показываются в платёжном окне Telegram. Доступ открывается после серверного successful_payment.
Отмена окна, callback «paid» на клиенте и нажатия без успешного платежа не выдают товар.
Кнопка «Восстановить покупки» загружает товары этого Telegram-аккаунта с сервера. Она не покупает их снова.
Цены задаёт SHOP_CATALOG в Worker; игра получает их от сервера. Перед изменением цен действующих товаров проверь незавершённые счета.

ПРОГРЕСС И ВОССТАНОВЛЕНИЕ
Обычный прогресс остаётся в localStorage под прежним ключом obby_smash_rush_tg_save_v1. Схема обёртки 1 и версия прогресса 2 сохранены.
На том же домене и в том же WebView используются прежние монеты, уровни и заработанные скины. Не очищай данные игры ради обновления.
Оплаченные скины и постоянные бонусы хранятся отдельно в D1 и восстанавливаются по проверенному Telegram ID, в том числе после смены устройства. Для проверки оплаченного доступа нужен интернет и рабочий Worker.
Переноса обычных монет и рекордов между устройствами в этом обновлении нет.
Возврат снимает соответствующий оплаченный доступ после обновления магазина / перезапуска. Заработанные за монеты или рекламу скины не отзываются.
Комплект включает текущие 40 костюмов. Будущие костюмы в состав не обещаны.

ПОДДЕРЖКА ПОКУПОК
/terms — условия покупок.
/purchases — список постоянных покупок аккаунта.
/paysupport описание проблемы — сохраняет обращение для владельца игры.
На странице Worker: введи WEBHOOK_SECRET → «Покупки и обращения». Можно ответить игроку через бота, отметить обращение обработанным и выполнить подтверждённый возврат Stars.
Регулярно проверяй обращения. Возвраты относятся к реальным платежам: перед нажатием проверь заказ и сумму.
При необходимости кнопка «Отключить новые покупки» останавливает создание счетов; восстановление уже оплаченных товаров продолжает работать.
Повторные уведомления одного платежа не выдают товар ещё раз. Повторный реальный платёж по уже оплаченному счёту записывается и возвращается.

ЗАГРУЗКА И ВОЗВРАТ В ИГРУ
Telegram SDK подключается асинхронно. Его недоступность не останавливает загрузку самой игры.
На экране загрузки показывается ход загрузки. При ошибке или загрузке дольше 90 секунд доступна кнопка повторной загрузки без удаления сохранений.
При сворачивании временные размеры 0×0 / 1×1 не перезаписывают размеры игрового поля. Устаревшая маленькая высота Telegram после возврата игнорируется.
При потере WebGL-контекста предлагается перезагрузка с сохранением уже записанного прогресса, вместо молча сломанного изображения.
Окно ожидания рекламы появляется только при настоящем рекламном запросе, не при оплате и обычном сворачивании.
Новый игрок сначала видит обучение: тап → забег. Дополнительные разделы появляются после первого забега. Существующий игровой прогресс не сбрасывается.

ADSGRAM
Reward blockId 57445, production debug:false. Реклама необязательна.
Общая пауза после успешной награды — 90 секунд; повтор +10 000 монет — через 10 минут. Stars с этими таймерами не связаны.

ИСХОДНИКИ И ПРОВЕРКИ
Godot 4.5.1, Compatibility/WebGL2, однопоточный Web без COOP/COEP. Пресет Web - Telegram.
После экспорта: python3 tools/finalize_telegram_web.py /полный/путь/к/Web 079
Код оплаты на клиенте: web/stars_bridge.js, scripts/stars_store.gd.
Полный сервер, SQL и тесты: telegram_backend/. Владелец может вставить готовый worker.js целиком в Cloudflare без сборки.
Ни BOT_TOKEN, ни WEBHOOK_SECRET в клиенте или архивах нет. В тестах стоят только явно фиктивные значения.
VALIDATION_079.json содержит результаты. Сервер и SQLite, клиентский мост и сам Web-билд проверяются локально. Telegram API и нативное окно оплаты имитируются; настоящие Stars не списывались.
Физическое устройство друга и фотографии из пересланной переписки были недоступны: исходная причина его сбоя не установлена. Проверены соответствующие сценарии изменения окна и восстановления.
