OBBY SMASH RUSH — TELEGRAM 083 / 0.8.3

УСТАНОВКА
1. Распакуй ObbySmashRush_Telegram_Web_083.zip.
2. Скопируй содержимое с заменой файлов в прежний репозиторий Obby-Smash-Rush.
   index.html, index.js, index.wasm, index.083.pck должны лежать в корне.
3. GitHub Desktop: Commit to main → Push origin. Дождись успешного Pages.
4. Закрой и заново открой Mini App. В настройках должна быть версия 0.8.3.

КАК НАЙТИ НОВЫЙ ТРЕК
Шестерёнка → Музыка → Саундтрек → Rushline.
Он пятый в списке песен; над песнями остаётся режим общего плейлиста.
В общем плейлисте Rushline играет после Frost Drift, затем возвращается
Skyline Bounce. Можно выбрать Rushline отдельно: он будет повторяться.
Выбор сохраняется. Старые настройки трека не сбрасываются.

Rushline — тот самый оригинальный трек из трейлера V3, 37,5 секунды, 128 BPM.
Громкость согласована с остальными четырьмя композициями.
В настройках всех 10 языков теперь указано 5 треков.

Обновление включает исправления 082: адаптивный Ultra, переиспользование
обломков, плавное прохождение стен и баланс монет в магазине улучшений.
Сохранения, оплаченные скины, Worker, D1 и Adsgram не требуют перенастройки.
Обновляй на прежнем адресе и не очищай данные браузера или Mini App.
